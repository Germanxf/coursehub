DEMOSTRACIÓN REQUERIDA - SEMANA 6: CONSULTAS DE DATOS


1. Crear suficientes cursos para mostrar dos páginas de resultados

Crear Curso 1:
- Metodo: POST
- URL: http://localhost:3000/courses
- Headers: Content-Type: application/json
- Body:
{
  "title": "NestJS Básico",
  "level": "principiante"
}

Respuesta Esperada (201 Created):
{
  "id": 1,
  "title": "NestJS Básico",
  "level": "principiante"
}

(Repetir para crear al menos 6 cursos con niveles: principiante, intermedio, avanzado)
